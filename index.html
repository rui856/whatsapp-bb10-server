What it does

Text, media & audio

Send and receive text, images, voice notes and video — with server-side conversion tuned for BB10.

Your data, at home

Runs in Docker on your own box. Messages and media live in a local SQLite DB and media folder.

Reactions & replies

Emoji reactions, quoted replies, profile pictures, unread badges and multi-device sync — all supported.

Server-side time

Timestamps are formatted on the server, so old phones with stale tz data always show the right time.

Cloudflare Tunnel

No open ports, no static IP needed. Exposed to the internet securely over HTTPS via a Zero Trust tunnel.

OTA app updates

The BB10 client checks the server for new APK builds published straight from GitHub Releases.
